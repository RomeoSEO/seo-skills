# RomeoSEO skills for Claude

50 free SEO, AEO, LLM SEO and GEO skills from RomeoSEO. This branch contains the Claude directory package. Each skill is a Markdown instruction file; review each skill before using it.

The skills are MIT licensed. Some optional integrations require accounts or credentials; follow each skill’s instructions and the provider’s terms.

Source: https://github.com/RomeoSEO/seo-skills
Website: https://romeoseo.com/skills

This package was prepared from source commit e2fed0c2e1c53840f0f04d0c6868d3931f2e7bea. Updates to the source skills must be synchronized to this branch before the Claude directory can pick them up.

## Data and third-party services

These skills are instructions, not a hosted service, and do not include a connector. Depending on the task, the assistant may read and write user-provided website content, reports and files, which may contain personal information. Optional workflows use services chosen or connected by the user: Google Search Console, Analytics, PageSpeed Insights and Rich Results Test; Bing Webmaster Tools; DataForSEO; AI search services such as ChatGPT, Gemini, Claude and Perplexity; and publishing services, repositories or websites selected by the user. Those services receive the queries, URLs, code, content or credentials needed for the chosen operation and apply their own retention policies. Review private data and costs before using them. RomeoSEO does not receive data merely by installing this skills package; optional RomeoSEO integrations have their own privacy policy.
